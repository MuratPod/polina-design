# Aula. — Brandbook · Dirección D · Editorial

«Menos ruido. Más temario.» Papel `#F4F1EA`, tinta navy `#14213D`, oro `#D9A21B` solo como acento (texto dorado: `#856000`, AA).
Fraunces + IBM Plex Sans (+ IBM Plex Mono para fórmulas), OFL, self-hosted en `fonts/` (sin CDN).

Abrir `index.html`. Resumen: `png/board-summary.png`. Regenerar: `bash build.sh` (Python 3, fontTools, Pillow, Playwright + Chrome); el build comprueba desbordamientos.

Carpetas: `logo/` (horizontal, apilado, marca, verticales, on-dark, mono, zona de respeto) · `app-icon/` · `favicon/` · `web/` · `ui/` (CSS, UI kit claro/oscuro, hoja de logo, ΔE competencia) · `screens/` · `templates/` · `icons/` · `tokens/` (JSON, CSS, contrast.json).

Correcciones incluidas: subtle `#66697F`, success-100 `#E6F5F2`. Iconos: mismo set que Impulso, trazo 1,5.
Pendiente de decisión: navy `#14213D` está a ΔE2000 6,6 del navy de MAD `#11184A` (alternativa `#142A3D`, ΔE 10,9). Textos de App Store: provisionales.
