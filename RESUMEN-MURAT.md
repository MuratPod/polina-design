# Sala (рабочее название) — первый дизайн-концепт для Полины

**Что сделано** (`/workspace/polina-design/`):
- `index.html` — один самодостаточный файл: сверху moodboard (3 прилагательных, палитра, шрифты, компоненты), ниже кликабельный прототип в рамке телефона 390 px + заметки по каждому экрану («зачем», что берём у Duolingo, что сознательно отвергаем, адаптация под десктоп). 12 видов: Inicio, Estudiar, Lección, Feedback (верно/ошибка), Simulacro (старт + во время экзамена с таймером), Ficha, Revisión de ficha, Actualidad, Tutor, Ajustes.
- `CONCEPTO.md` — концепт на испанском для Полины (визуальное направление, карта навигации, таблица по экранам, приоритет PoC).
- `README.md` — как открыть.

Стиль: глубокий «музейный» сине-зелёный + бумажный фон + терракота/золото только для XP/серии; Source Serif 4 + Inter. Никакой совы/зелёного Duolingo. AI-объяснения везде с бейджем «Contenido IA» и ссылкой на источник (BOE / CER.es). Весь контент — примеры.

**Как открыть:** двойной клик по `index.html` или `cd /workspace/polina-design && python3 -m http.server 8000` → http://localhost:8000. Прямые ссылки на экраны: `#leccion`, `#fb-err`, `#sim-run`, `#ficha-fb`. В уроке вариант B = верный ответ.
