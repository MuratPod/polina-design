# A · Noche de estudio

**Идея.** Библиотека поздно вечером: глубокий ночной синий градиент, тёплое «ламповое» золото и редакционная антиква. Тон спокойный и взрослый, как у человека, который готовится к экзамену годами. Знак — арка (портал, аула) с точкой-лампой над ней, рядом золотой словесный знак «Aula» на тёмно-синем. Градиент идёт сверху вниз под 160°, как свет, падающий на стол.

- Шрифты (OFL, self-host, `../fonts`): **Fraunces** (заголовки, словесный знак) + **Public Sans** (UI).
- Палитра и контраст: `palette.json`. Логотип: `logo-aula.svg`. Мокап: `mobile.png` (390 px).
- Вертикали: акцент только в бейдже вертикали, у активной вкладки темы и в тонкой линии карточки. На светлом фоне используется `*Deep` с белым текстом, на ночном синем — светлый тон. Museos `#E0906A` / `#A5583A`, Justicia `#D98A97` / `#8E3445`.
- Правило: акцентный текст на светлом конце градиента (`#1E3D6B`) только крупный (≥3:1).

Copy UI (ES): «Estudia como se examina.», «Empezar lección», «Simulacro · Examen completo».
