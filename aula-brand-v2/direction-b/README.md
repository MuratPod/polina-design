# B · Constelación

**Идея.** Точность и маршрут: градиент от тёмно-синего к индиго с еле заметной сеткой звёздной карты. Каждая выученная тема — звезда, а программа экзамена — созвездие. Знак — буква A из трёх звёзд, соединённых линиями, и словесный знак «AULA» геометрическим гротеском в разрядку. Ощущение современного «прибора», без школьной геральдики.

- Шрифты (OFL, self-host, `../fonts`): **Outfit** (заголовки, словесный знак) + **IBM Plex Sans** (UI, табличные цифры).
- Палитра и контраст: `palette.json`. Логотип: `logo-aula.svg`. Мокап: `mobile.png` (390 px).
- Вертикали: акцент задаёт цвет «своего созвездия» (звёзды сетки и прогресс по темам), бейдж и линию. На светлом фоне используется `*Deep` с белым текстом. Museos `#E07B53` / `#A94E2C`, Justicia `#6FA8DC` / `#2F6AA3`.
- Правило: Museos-текст на светлом конце градиента (`#2A2E7C`) только крупный (≥3:1).

Copy UI (ES): «Estudia como se examina.», «Empezar lección», «Simulacro · Examen completo».
