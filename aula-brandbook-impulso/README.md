# aula! — брендбук · C · Impulso (черновик дизайна)

Открыть `index.html`: одна статичная страница, все ассеты по относительным путям, читается на телефоне. Сводная доска: `png/board-summary.png`.
Пересборка: `bash build.sh` (Python, fontTools, Pillow, Playwright с `/usr/bin/google-chrome`).

## Почему так
- **Основа C · Impulso** (выбор Мурата): тёплый фон #FFF8EC, Nunito, коралл + синий #2E5BFF. Стиль «игровой, но взрослый», в центре серии и мотивация.
- **Коралл сдвинут к розово-красному**: #FF4250, тон 355,6°. У OpositaTest #EF7746 тон 17,4°, разница по тону 21,8°, ΔE2000 = 15,6 (у прежнего #FF6B3D было 3,8, то есть почти тот же цвет). Для текста используется #C8162B (5,52:1 на фоне).
- **Navy + золото** — тёмная пара бренда, а не только тёмная тема: hero, шапка приложения, серия, XP, футер. В тёмной теме эта пара становится основой.
- **Успех** — бирюзовый #0E7A6E, а не зелёный Duolingo. Ошибка — кирпично-красный #B42318: всегда с иконкой и текстом, чтобы не путать с кораллом.
- **Вертикали** отличаются только бейджем, линией на карточке, символом и активной вкладкой. CTA всегда коралловый: Museos — охра, Justicia — слива, Policía — петроль, Educación — оливковый.
- **Без** сов, маскотов, жизней, лиг, гербов и печатей. Без «Duolingo» и «garantía de aprobado».
